# Account domain

Server-only schema/identity/commands/rate budgets are separate from client form components. Routes compose these modules with the current application shell and semantic theme. The existing `src/lib/auth` pure contracts remain; do not turn a client snapshot into authority. Native Auth owns sessions/factors; PostgreSQL commands derive the actor, recheck suspension/session, write transactionally and append audit. Public/hosted launch remains disabled. See `docs/auth/LOCAL_ACCOUNTS.md` and ADR 0003.
