# Duzelo — visual identity exploration, October 2026

## Working name decision

**Retain Duzelo as a *working name*.** The repository, domain and prelaunch copy already use it; avoid a disruptive rename until South African CIPC, trademark, app store, domain and relevant common-law checks are completed. Alternatives for founder review: **Ndlovu Nearby** (clear locality but strong surname overlap), **HambaHelp** (translation and existing-use clearance needed), **Duzelo** (short, distinctive sounding, currently provisional). These are brainstorming names, NOT legal availability claims.

## Brand system

- Positioning: A neighbourhood service desk, not a generic gig platform.
- Tagline: **A little help. A lot closer.** Retain "Good help, close to home" as fallback SEO/longform copy.
- Identity: an original circular link/wayfinding symbol, drawn as two paths meeting at the central warm dot. Use one mark for brand, PWA icon, app mask and favicon.
- Typography: Geist Sans for function, Geist Serif for editorial accents and impactful headlines.
- Palette: warm paper (#F9F7F0), deep pine ink (#172920), forest (#123E35), muted sage (#E8EEE6), ochre (#F6BC5C). Prefer themed tokens to per-page values.
- Component inspiration: EasyUI's MIT Spotlight Card approach adapted as CSS pointer-driven enhancement, with accessible keyboard and touch fallback; motion with GSAP currently present (do not add a duplicate animation runtime just for decoration).
- Interface Lineage principles: one obvious next action, visible previews, no ambiguous "processing" theatre, progressive explanation over false claims, and reduced-motion support.
- Editorial demo requests are **fictional**; use no invented user profiles, payments, response times, ratings, or worker approvals.
- No user logo inspiration image was present in this conversation's attachments. Original SVG is a provisional artwork, pending comparison against the founder's reference.
- Before public rollout: trademark/wordmark clearance and approval of identity imagery.
