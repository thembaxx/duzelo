# Founder inspiration analysis — 2026-10-31

## Observed traits to adapt

- Light finance/health dashboard references: large calm surfaces, compact pill navigation, rounded panels, generous but structured spacing, lime/olive and warm peach highlights.
- Dark mobile companion/wishlist references: charcoal layered surfaces, strong text hierarchy, softly bordered cards, concentrated accent color and a floating rounded bottom bar.
- Photo-editing control references: restrained controls, visible selection, precise spacing and a dark high-contrast canvas.
- Stacked analytics reference: generous corner radii and soft color transitions; useful as surface inspiration rather than as an actual chart requirement.

## Boundaries

Do not copy logos, mascots, screenshots, user identities, photos, proprietary imagery, data visualizations or distinctive app layouts wholesale. Reference images are not distributed as product assets or committed to the public repository. No people are identified. The source screenshots’ financial, health and AI data have no place in this local-services product. Use the agreed PRD information architecture.

## Applied token and layout changes

Use a charcoal base (`#121311`), readable warm-white (`#f4f5ee`), lime (`#d5f478`) primary actions and warm peach (`#ebc8b2`) locality note. Add sage/lilac icon backgrounds for category recognition. The hero has a restrained olive ambient highlight with abstract CSS rings, not final imagery. Card radii are 20–28px; default buttons and navigation are capsules. Responsive desktop navigation becomes a floating four-link mobile bar.

No application UI existed before references arrived, so there is **no fabricated before screenshot**. The original text pack is the before state. Implemented screenshots are recorded under `docs/evidence/screenshots` at 390×844 and 1440×900. Final brand imagery and sign-off remain open; later reference changes can be made through semantic tokens and shared components without changing authorization or workflows.
