# Provisional design system

Founder references received during Milestone 00. [Reference analysis](design/reference-analysis.md) records the adaptation. The working wordmark is plain configurable text; letter-only app icons are replaceable install placeholders.

Charcoal canvas, warm white text, lime primary actions, peach/sage/lilac secondary surfaces; rounded cards and capsule navigation. All colors and radii live in `src/styles/tokens.css`. Local system sans-serif avoids remote font requests. Line icons provide taxonomy cues without claiming real worker imagery or completed work.

Desktop sidebar and mobile four-link floating navigation expose implemented routes. Client/worker business navigation will arrive with actual capabilities. Minimum default button target is 44px; visible focus, skip-to-content, semantic headings, native details menu and reduced-motion support are included. Responsive CSS handles 320px without horizontal scrolling. Content is honest about pilot preparation.

English-first copy has no fake reviews, counts, verification, guarantees, prices or location matching. Draft legal preview notices explicitly require professional review. A small tonal glow decorates the hero without large motion or image downloads. No final brand sign-off or automatic legal certification is implied.
